# BM8 AI — Football Predictor

AI-powered football match predictions using Google Gemini.

## Deploy to Vercel

1. Import this repo to Vercel
2. In Vercel dashboard: Settings → Environment Variables
3. Add: `GEMINI_API_KEY` = your Gemini API key from https://aistudio.google.com/apikey
4. Deploy!

## Tech Stack
- React + Vite + TypeScript
- Vercel Serverless Functions (backend proxy)
- Google Gemini 2.5 Flash (AI)
